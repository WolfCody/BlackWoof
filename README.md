## Cargo.lock

Пока `Cargo.lock` не закоммичен, CI создаёт его заново при каждом запуске. Такой файл **не фиксирует версии зависимостей между отдельными запусками**: два запуска могут получить разные версии. Файл попадает в артефакт запуска (даже если запуск упал позже); закоммитьте его, после этого версии закреплены, а все команды Cargo идут с `--locked`.

## Проверка повторяемости (не воспроизводимость APK)

При `REPEAT_CHECK=1` скрипт собирает `libblackwoof.so` и `classes.dex` дважды в рамках одного запуска и сравнивает SHA-256 этих двух файлов. Это проверка повторяемости библиотеки и DEX внутри одного запуска. Сам APK не сравнивается, поэтому это не доказательство полной воспроизводимости APK.

## Подпись

Временный ключ создаётся в `RUNNER_TEMP` (вне репозитория), пароль передаётся через окружение и не печатается, ключ удаляется ловушкой `EXIT` при успехе и при ошибке. В репозитории ключей нет, в артефакты они не попадают.
